# Доступ PiTun к хосту

Статический аудит [зафиксированного дерева](UPSTREAM_BASELINE.md). При трассировке проверены Compose и Dockerfiles, регистрация API, lifecycle FastAPI, вызовы subprocess, Docker SDK и SSH, системные пути и эксплуатационные скрипты. Точки ниже показывают достижимые операции upstream. Для этапа 0 их изучали по коду.

Установка, bootstrap, полный router mode и удалённый provisioning отделяются от штатного MVP. Необходимые полномочия относятся к управляемым сетевым объектам: интерфейс/peers при kernel WG, policy routing/nftables и forwarding/NAT там, где этого требует топология, TUN при соответствующем адаптере. Доступ к host PID, системному resolver, Docker и право менять чужой default route для этой задачи не требуются. Критерии изоляции и оставшиеся эксперименты описаны в [ADR-001](adr/ADR-001-privilege-separation.md).
