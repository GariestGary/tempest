# Уведомления о сторонних компонентах

Этот файл описывает запланированное использование компонентов. Он не является завершённым аудитом поставки транзитивных зависимостей.

- **PiTun / TEMPEST** — BSD-3-Clause; полный текст и уведомление правообладателей находятся в [LICENSE](../LICENSE). Репозиторий сохраняет историю и авторство PiTun: <https://github.com/DaveBugg/PiTun>.
- **Xray-core 26.10.31** — MPL-2.0; [лицензия](licenses/xray-MPL-2.0.txt), [исходный код фиксированной версии](https://github.com/XTLS/Xray-core/tree/v26.10.31). Linux amd64 бинарник проверяется по SHA-256 `cc4b84d3069569f297a61f04b914f2bb37e9d202fd7b84cb50def1fc30fd40e1`. Образ существующего API включает Xray; при распространении образа следует сохранить доступ к соответствующему исходному коду и проверить уведомления зависимостей.
- **awgproxy** — ISC; [лицензия и copyright](licenses/awgproxy-ISC.txt), [исходный commit](https://github.com/mishamosher/awgproxy/tree/c87c35e40eddac260941ab02596e53d5eb601eae). Применён локальный [патч](../scripts/awgproxy-no-route-monitor.patch); воспроизводимая сборка и SHA-256 описаны в [WORKING_CORE_AWG](WORKING_CORE_AWG.md). Для linux/amd64 `CGO_ENABLED=0` собраны корневые лицензии модулей из `go list -deps` и Go stdlib с версиями и хэшами: [manifest](licenses/awg-dependencies/MANIFEST.tsv). Среди них amneziawg-go (MIT), go-socks5 (MIT) и gVisor (Apache-2.0). До распространения проверить вложенные notice/лицензии и соответствие фактически поставляемому бинарнику; текущий список не подтверждает завершения полного аудита поставки.
- **sing-box 1.14.2** — отдельная программа под GPL-3.0-or-later, с дополнительным указанием об имени в [оригинальном уведомлении](https://github.com/SagerNet/sing-box/blob/v1.14.2/LICENSE). Оператор самостоятельно получает [официальный выпуск](https://github.com/SagerNet/sing-box/releases/tag/v1.14.2), сохраняет его уведомления и проверяет бинарник SHA-256 `fc9c6e6ab345f045b16a0ed10d1ff28d68e8e56e7749fca30738d1406e98d7b8`. TEMPEST использует внешний исполняемый файл через отдельный systemd unit; бинарник sing-box не включается в репозиторий, контейнер API или подготавливаемый stage. Если в будущем он будет распространяться вместе с продуктом, условия распространения и исходники/уведомления зависимостей нужно проверить отдельно.

Производственный комплект образов и Go-бинарников пока не оформлен как redistributable release. Для первого частного развёртывания сохранить полные оригинальные лицензии и материалы исходных компонентов; перед дальнейшим распространением завершить аудит, включая транзитивные зависимости и условия поставки образов.
